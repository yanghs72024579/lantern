이야기꾼의 등불 — 독립판 사용법
==================================

Claude 구독 사용량을 쓰지 않고, 내 Claude API 키로 AI 이야기꾼을 부르는 판입니다.
쓴 만큼만 API 요금이 나가요(Haiku 5.5 기준 한 장면에 1~2원 정도).


1. API 키 만들기 (처음 한 번)
----------------------------------
1) platform.claude.com 에 로그인합니다(계정이 없으면 가입).
2) Settings → Billing 에서 크레딧을 충전합니다. 처음엔 5~10달러면 충분해요.
3) Settings → Limits 에서 월 사용 한도를 정해 두면 예상보다 많이 나갈 걱정이 없어요.
4) Settings → API keys 에서 Create key 를 눌러 키를 만듭니다.
   키(sk-ant-로 시작)는 만들 때 한 번만 보이니 바로 복사해 두세요.


2. 컴퓨터에서 하기
----------------------------------
1) 이 압축 파일을 풀어 폴더째 원하는 곳에 둡니다. (img 폴더와 index.html이 같은 폴더에 있어야 해요)
2) index.html 을 더블클릭해 크롬이나 엣지로 엽니다.
3) 시작 화면의 [AI 설정 · API 키] 를 눌러 키를 붙여 넣고 [연결 시험] → "연결됐어요!"가 나오면 끝.
4) 모험을 시작하면 됩니다. 진행은 그 브라우저에 자동 저장돼요.

※ 더블클릭으로 열었을 때 "인터넷 연결을 확인해 주세요"만 계속 나오면, 브라우저가 파일로 연 페이지의
   외부 연결을 막는 경우입니다. 아래 3번처럼 인터넷 주소로 올려서 쓰면 해결돼요.


3. 휴대폰에서 하기 (앱처럼 설치)
----------------------------------
휴대폰은 파일을 직접 열 수 없어서, 무료 웹 호스팅에 올려 주소로 엽니다. GitHub Pages 예시:

1) github.com 에 가입·로그인 → 오른쪽 위 + → New repository
   이름 예: lantern / Public 선택 → Create repository
2) "uploading an existing file" 을 눌러 이 폴더 안의 파일을 전부 끌어다 놓습니다
   (index.html, manifest.json, sw.js, icon-192.png, icon-512.png, img 폴더 통째로) → Commit changes
3) 저장소의 Settings → Pages → Branch 를 main / (root) 로 고르고 Save
4) 1~2분 뒤 https://내아이디.github.io/lantern/ 주소가 생깁니다.
5) 휴대폰에서 그 주소를 열고
   - 아이폰(사파리): 공유 버튼 → 홈 화면에 추가
   - 안드로이드(크롬): 메뉴 ⋮ → 앱 설치(또는 홈 화면에 추가)
   하면 아이콘이 생기고, 누르면 주소창 없이 앱처럼 열려요.
6) 처음 열 때 [AI 설정]에서 키를 넣습니다. (기기마다 따로 넣어야 해요)

※ 공개 저장소에 올리는 건 게임 파일뿐이고, API 키는 올라가지 않아요(키는 각 기기 브라우저에만 저장).
   그래도 주소를 아는 사람은 게임을 열 수 있으니, 원치 않으면 주소를 공유하지 마세요.


4. 진행 옮기기 (원래 게임 → 독립판, 컴퓨터 ↔ 휴대폰)
----------------------------------
- 저장은 기기·브라우저마다 따로예요. 자동으로 옮겨지지 않습니다.
- 옮길 때: 원래 게임(또는 다른 기기)에서 위쪽 [기록] → 맨 아래 "저장" → 내보내기로 저장 파일(또는 글)을 받습니다.
- 독립판에서는 아무 모험이나 새로 시작한 뒤 [기록] → "저장" → 불러오기로 그 파일(또는 글)을 넣으면
  가져온 캐릭터로 바뀌어 이어서 할 수 있어요.
- 가끔 내보내기로 백업해 두세요. 브라우저 기록을 지우면 진행도 지워질 수 있어요.


5. 비용 보기
----------------------------------
- 게임 화면 아래 "이번 장면 ○원 · 이번 달 ○원"을 누르면 오늘/이번 달/전체 사용액이 나와요.
- 응답에 적힌 토큰 수로 계산한 예상값이라 실제 청구와 조금 다를 수 있어요. 정확한 금액은 콘솔의 Billing에서 보세요.
- 모델은 AI 설정에서 바꿀 수 있어요. Haiku 5.5(권장, 저렴) / Sonnet 5.5(문장이 더 좋지만 약 20배 비쌈).


6. 주의
----------------------------------
- 키는 이 기기의 브라우저에만 저장되고 Anthropic 서버로만 보내져요. 남과 같이 쓰는 컴퓨터에는 저장하지 마세요.
- 키가 새어 나간 것 같으면 콘솔 API keys에서 그 키를 지우고 새로 만드세요.
- 원래 판에서 새 장소·새 몬스터 그림이 자동으로 생기던 기능은 독립판에는 없어요. 그런 곳은 기본 그림으로 보여요.


7. 새로 생긴 것
----------------------------------
- 야영: 마을 밖에서 위쪽 [야영]을 누르면 쉬어요. 체력과 스킬이 회복되지만 위험한 땅일수록 밤에 습격받기 쉬워요. 하루 한 번.
- 상태 이상: 화상·출혈·공포(전투 중), 저주(풀 때까지 판정 -2, 공격 약화). 물약은 출혈을, 해독제는 독을,
  성수와 신전 기도는 저주를 풀어요.
- [기록]에 의뢰 일지, 연대기, 몬스터 도감, 자동 백업(게임 속 하루마다 최근 3일치)이 있어요.
  자동 백업은 이 기기 안에만 있으니, 가끔은 내보내기로 파일 백업도 해 두세요.

8. 후반 콘텐츠 (마을 상점의 새 탭)
----------------------------------
- 게시판: 날마다 현상금 수배서 3건. 두 건까지 맡을 수 있고, 대상이 있는 지역에 가면 추적과 대결로 이어져요.
  쓰러뜨리면 아무 마을 게시판에서 보상(골드·경험치·명성)을 받아요.
- 집: 마을에 집을 마련하면(300골드) 무료로 푹 쉴 수 있어요. 창고(가방 +6), 작업장(강화 25% 할인),
  약초밭(하루 한 개씩 약초 물약)을 지을 수 있어요.
- 마구간: 말(250골드)은 여정을 1단계 줄이고 가방 +4. 항구에서는 배(900골드)를 사서 바다 건너
  미지의 땅 여섯 곳으로 항해할 수 있어요.

9. 효과음
----------------------------------
- 위쪽 [소리] 버튼을 누를 때마다 보통 → 크게 → 작게 → 끔으로 바뀌어요.
- 화면을 한 번 누른 뒤부터 소리가 나요. 아이폰은 무음 모드에서는 소리가 안 날 수 있어요.
- 소리는 브라우저가 직접 만들어 내는 것이라 API 요금이나 인터넷이 필요 없어요.
