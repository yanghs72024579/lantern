AI 이야기꾼 설정

Claude API 키로 이야기꾼을 부릅니다. Claude 구독 사용량과는 따로, 쓴 만큼만 API 요금이 나가요.

  1. platform.claude.com에 로그인하고 결제(Billing)에서 크레딧을 충전해요.
  2. Settings → API keys에서 Create key로 키를 만들어요. sk-ant-로 시작해요.
  3. 아래에 붙여 넣고 연결 시험을 눌러 보세요.

사용 비용 (응답에 적힌 토큰 수로 계산한 예상값 · 1달러 = 원)

키는 이 기기의 이 브라우저에만 저장되고, 이야기를 만들 때 Anthropic 서버로만 보내져요. 다른 사람과 같이 쓰는 기기에는 저장하지 마세요. 정확한 청구액과 월 한도는 콘솔의 Billing·Limits에서 확인하고 정할 수 있어요.
